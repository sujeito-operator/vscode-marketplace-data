Two of these figures are easy to quote wrongly, so they are spelled out. Every “under N installs” percentage is a floor: the crawl paged from the most-installed downwards, so everything it missed is smaller than everything it found. And installs are not revenue — the VS Code Marketplace has no paid tier, so nothing here measures money.
