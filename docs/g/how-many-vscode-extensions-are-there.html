How many VS Code extensions and publishers are there?

A August 2026 crawl reached 64,464 extensions from 50,446 publishers, holding 5,688,436,895 installs. Why that is a floor and not a total.

Why nobody can honestly give you the total

The Marketplace does not publish a count, and its query API pages results rather than answering “how many”. Any figure you see quoted is somebody’s crawl depth. This one enumerated each category in the Marketplace’s own taxonomy sorted by installs and paged down until a cap, so what it missed is entirely below what it found. The true count is larger and the true median is lower.

The published figure is therefore written as what it is: 64,464 extensions reached, holding 5,688,436,895 installs between them. If you need a census, this is not one, and the collector is in the repository so you can go deeper yourself rather than argue with the number.

Publishers, and the shape of them

86.1% of publishers have published exactly one extension. This is not a market of software vendors with catalogues; it is a very long tail of single releases standing behind a small number of large ones. The largest single publisher account in the sample carries 286.
