How much of the VS Code Marketplace is abandoned?

65.2% of measured extensions have not been updated in twelve months — and the stale ones have a higher median install count than the current ones. By category, with the age confound stated.

Read this before quoting anythingThis is not a census and it is head-biased: each category was paged from the most-installed downwards until a cap, so the tail below the cap is missing. Every “under N installs” figure here is therefore a floor, not an estimate — the true share is higher, because everything the crawl did not reach lies below everything it did.
65.2% of the extensions in this sample have not been updated since 2025-08-08. The surprise is which ones: the stale set has a median of 1,350 installs and the actively-updated set has 103. The abandoned half of this marketplace is the bigger half.

Because “stale” and “old” are the same population

An extension that shipped in 2018 and stopped in 2021 has had years to accumulate installs; one published last month is fresh by construction and has had none. Sorting on last-updated therefore sorts, mostly, on age — and age is what drives a cumulative counter. Read the two medians as a warning about the split rather than as a finding about maintenance.

What the split does support: a large install count on the VS Code Marketplace is not evidence that anybody is still maintaining the thing. 65.2% of what is installed from here has not been touched in a year.
